# ToDoo App

**ToDoo App** is a simple and user-friendly web application to manage your daily tasks efficiently.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clean and simple UI

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the project in your browser.
2. Add your tasks in the input box.
3. Click **Add** to save the task.
4. Mark tasks as completed or delete them when done.

## Future Scope
- Add local storage to save tasks permanently.
- Add user authentication to save tasks online.
- Add a priority feature to tasks.
- Convert it to a mobile-friendly app.
